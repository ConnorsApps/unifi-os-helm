# Changelog

Chart releases, newest first. Each section names the UniFi OS Server release
it packages (the image tag is the chart's `appVersion`). `make upgrade` and
`make upgrade-verify` maintain the entries for upstream upgrades.

## 0.10.2

UniFi OS 5.1.42 (released 2026-09-10), unchanged from 0.10.1.

- Added a JSON schema for the chart values (`values.schema.json`, generated by `cmd/schema-gen` with `make schema`; `make schema-check` fails when it is stale).
- `values.yaml`, `values.env.example.yaml` and the README values example start with a `# yaml-language-server: $schema=` comment pointing at the raw schema on `main`, so editors validate and complete values.
